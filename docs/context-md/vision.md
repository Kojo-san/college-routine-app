1 Introduction
Le projet College Routine est une plateforme intelligente de gestion de performance
| humaine destinée   | principalement |              | aux         | étudiants     | universitaires. |     |     |
| ------------------ | -------------- | ------------ | ----------- | ------------- | --------------- | --- | --- |
| L’objectif         | du système     | est          | d’optimiser | simultanément |                 | :   |     |
| — la réussite      | académique;    |              |             |               |                 |     |     |
| — la santé         | physique;      |              |             |               |                 |     |     |
| — la récupération; |                |              |             |               |                 |     |     |
| — la gestion       | du stress;     |              |             |               |                 |     |     |
| — l’organisation   |                | quotidienne; |             |               |                 |     |     |
| — le développement |                | d’habitudes  | durables.   |               |                 |     |     |
Le système agit comme un assistant intelligent capable de générer des recommanda-
tions personnalisées et des planifications dynamiques basées sur :
| — les horaires  | de             | cours;         |           |         |     |         |     |
| --------------- | -------------- | -------------- | --------- | ------- | --- | ------- | --- |
| — les plans     | de cours;      |                |           |         |     |         |     |
| — les échéances | académiques;   |                |           |         |     |         |     |
| — les objectifs | de             | l’utilisateur; |           |         |     |         |     |
| — les données   | physiologiques |                | provenant | d’Apple |     | Health; |     |
| — les habitudes | de             | vie;           |           |         |     |         |     |
— des recherches scientifiques en neurosciences, productivité, sommeil et apprentis-
sage.
